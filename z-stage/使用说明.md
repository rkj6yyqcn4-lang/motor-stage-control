# Z 轴位移台驱动

基于用户提供的 `test_x_axis_hk_daq.m` 改写为 C# Windows Forms 桌面程序。使用同目录的原厂 `USBDAQ_DLL_V12X64.dll`，不依赖 MATLAB，不需要安装 Visual Studio，不含固定盘符路径。复制整个文件夹后双击 `ZStage.exe`。

## 运行条件与复制方式

- 目标平台：Windows 10/11 x64、.NET Framework 4.x，厂家对应版本的板卡 USB 驱动已安装且板卡可正常识别。
- 应用按 x64 编译，不能在 32 位 Windows 上运行。
- 将“z轴位移台驱动”整个文件夹复制到目标电脑的普通可读目录；不要只复制 EXE。可使用中文路径。
- 已随包放入来自本机 Visual Studio `VC/Redist/MSVC/14.51.36231/x64/Microsoft.VC145.CRT` 的 VC++ 可分发 DLL，供厂家 DLL 本地加载。系统 UCRT、.NET Framework 和板卡内核驱动仍由目标 Windows 提供。
- 无需重新编译。仅修改源码时才运行 `build.cmd`。
- 同一时间只允许本控制程序的一个实例运行。请先关闭 MATLAB、厂家调试软件及其他占用同一板卡的程序；本程序不能阻止其他软件控制板卡。
- 不自动连接或自动运动。退出后重新打开，不会恢复上次运动。

已完成本机编译和模拟板卡测试；尚未连接真实板卡/位移台，也未在另一台电脑上实测。目标电脑驱动是否匹配、PWM 100% 是否确实保持高电平、物理上下方向以及实际停止时间，需要现场验收，不能仅凭软件测试保证。

## 接线（共阳极，与原 MATLAB 文件一致）

| 板卡端口 | 驱动器端口 | 作用 |
| --- | --- | --- |
| 5VO | PUL+ | 脉冲正端 |
| PWM1 | PUL− | 脉冲负端 |
| 5VO | DIR+ | 方向正端 |
| OUT3 | DIR− | 方向负端 |

`PWM1` 在厂家接口中为 PWM 通道 **1**；`OUT3` 在 `DoSetV12` 中为数字输出通道 **2**，不是 3。ENA 未由程序控制，沿用原文件未接 ENA 的方案。电气电压和驱动器输入要求以实际硬件说明书为准。

运动占空比为 **50%**；停止占空比为 **100%**，意图是让 PUL− 保持高电平、停止产生步进脉冲。停止时不切换方向、不主动释放电机保持力，也不控制其他轴。

## 第一次操作

1. 确认位移台远离上下端点，并具备可立即使用的硬件急停措施。
2. 双击 `ZStage.exe`，点击“连接板卡”。连接成功后，程序先发送 PWM1 停止命令。
3. 首次将频率设为 100–300 Hz，将单次时长设为 0.1–0.5 秒，用短行程确认方向。程序初始值为 200 Hz、2.0 秒，可以在运动前调整。
4. 点击“上移”或“下移”。一次点击执行一次限时运动，到达设定时长自动停止；无需按住按钮。
5. 若方向相反，先停止，再勾选“反转上下方向”。默认上移 `OUT3=1`，下移 `OUT3=0`；这只是电平约定，不代表已标定物理方向。反转选项不跨重启保存。
6. 运动中随时点击红色“停止”。程序在鼠标按下时就提交停止请求；空格或 Esc 也可停止。
7. 调整参数和再次运动前，应等待界面显示已停止。运动中不允许点击另一方向直接反向。
8. 完成后点击“断开板卡”，或直接关闭窗口。程序先发送停止命令，再关闭板卡。

## 参数与停止行为

- 脉冲频率输入范围：1–10000 Hz。上限沿用原文件中的 10000 Hz 数值，仅是软件输入限制，不代表位移台适合在此频率运行。
- 单次时长范围：0.1–60 秒。是软件计时停止，不是硬件脉冲计数；Windows 调度和 USB 通讯会影响实际时长。
- 改变方向前先发送停止命令，设置 OUT3 后留出至少 50 ms 方向建立时间。
- 所有厂家函数均在专用线程串行调用。界面不使用 `Sleep` 或长循环等待运动完成。
- 停止请求优先于待执行的运动，清除排队的运动，并可取消方向建立阶段，避免松开/停止后延迟启动。
- 窗口失去焦点、最小化或关闭时请求停止；这是额外的防误动行为，切换到其他软件也会停止运动。
- 若厂家 DLL 正在执行同步 USB 调用，停止命令必须等该调用返回后发送。点击停止不再等待原来的运动时长，但不能保证零毫秒响应或机械零位移。
- “已停止”表示停止接口返回成功；板卡没有提供在本程序中使用的停止到位反馈，界面不能独立确认机械运动已完全停止。
- 若停止接口返回失败或抛出异常，显示“停止未确认”，锁定后续运动，保留板卡句柄；可再次点击停止重试。故障恢复需要停止成功后断开、重新连接。
- 关闭窗口时若停止/断开失败，窗口保留并显示故障，不会把失败误报为安全退出。

## Z 轴的现场验收与限制

当前接线只包含脉冲与方向。本程序没有接入上下限位、原点、编码器、抱闸或驱动报警，也没有做毫米位移、回零或位置闭环。频率不等于 mm/s；缺少丝杆导程、细分和脉冲当量，不能准确换算行程。

真实设备验收时，先低速短时点动，确认上下方向和脉冲停止电平；再在短行程中点击停止，观察机械实际响应。停机时还需确认 Z 轴的保持/抱闸行为。不要将“切断驱动器动力”视为垂直负载必然安全保持的办法，现场应依靠适当的机械支撑、抱闸和急停设计。

软件停止不能代替硬件急停。USB 拔出、厂家函数永久卡住、程序被强制结束、电脑断电等情况下，PC 软件无法保证板卡停止独立输出 PWM；这也是无法承诺所有故障下“立即停止”的原因。

## 文件结构

- `ZStage.exe`：64 位图形界面，直接运行。
- `ZStage.exe.config`：指定 .NET Framework 4.x CLR。
- `USBDAQ_DLL_V12X64.dll`：从原驱动电机文件夹复制，未改动。
- `msvcp140*.dll`、`vcruntime140*.dll`、`concrt140.dll` 等：VC++ 可分发运行库。
- `src/Program.cs`：中文 WinForms 界面和程序入口。
- `src/Controller.cs`：板卡 P/Invoke、专用线程、方向/停止/关闭逻辑。
- `src/Tests.cs`：模拟板卡测试，不连接真实板卡。
- `reference/`：原 MATLAB 文件和厂家头文件，便于对照。
- `build.cmd`：使用系统 .NET Framework x64 C# 编译器重编译，不需要 NuGet。
- `self-test.cmd`：运行模拟测试并生成 `self-test-report.txt`；不会连接真实板卡。
- `测试记录.txt`：本次构建的测试结果，不能作为真实设备测试报告。
- `界面预览.png`：未连接状态的界面。
- `SHA256.txt`：交付文件哈希。

## 故障排查

- 找不到 DLL：确认整个目录已完整复制，运行库 DLL 与 EXE、厂家 DLL 位于同一层。
- `BadImageFormatException`：一般为 DLL 位数不匹配；本程序要求 x64 厂家 DLL。
- `DllNotFoundException`：也可能是厂家 DLL 的间接依赖缺失，或系统 UCRT/运行库版本不兼容，不仅仅是主 DLL 不在。
- `EntryPointNotFoundException`：厂家 DLL 版本/导出名不同；应使用本包所附原始 DLL，并核对头文件。
- `OpenUsbV12` 非零：检查驱动、USB 连接、板卡占用和厂家工具；错误码保留在界面日志中。
- 电机不动：检查共阳极接线、驱动器使能和动力电源；确认 PWM1/OUT3 没有被其他程序修改。
- 停止未确认：执行现场硬件急停流程，处理通讯或设备故障，再重试软件停止和重连。不要仅凭按钮颜色判断设备已停止。
